# Tape Deck Drift v0.2.0
HTML5 cassette rhythm racer by Arthur McConnell / Retro Gaming Dad. Single file `index.html`, 360x640 portrait canvas.

## v0.2.0
- Original layered WebAudio mixtape BGM per deck (kick/snare/hats, bass, chords, lead); tape warbles when stretched. Music toggle (title, pause, M key).
- 6 decks / 12 sides: Boombox 84, Walkman XR, Chrome ZX-9, Dolby Nights, Hi-Bias 90, Metal Type IV. Clear a B-side to unlock the next deck. Later sides are longer with more off-beats and tangles. Old saves keep their unlocked count.
- Pause (Esc / P / pause button): Resume, Restart Track, Quit to Tape Menu, Quit to Title, Music.
- Screens: Title, How to Play, Credits, Tape Menu, Play HUD, Pause, Rewind (ad), Clear / Game Over (Next / Retry / Menu / Title).
- RunAds stubs kept (not deployed to RUN).
